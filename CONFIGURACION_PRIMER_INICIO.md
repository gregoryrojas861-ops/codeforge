# Primer inicio

El instalador contiene la aplicación generada por PyInstaller, por lo que el usuario final no necesita instalar Python.

Ollama es opcional para IA local. Las claves de proveedores externos no deben incluirse en el código ni en el instalador.

La distribución recomendada es:
CodeForgeAI_Setup.exe -> instalar -> acceso directo -> abrir.
